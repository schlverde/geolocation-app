# GeoLocationApp

An Ionic Angular geolocation application that retrieves the user's current location and displays it on an interactive map.

## Features

- Get current location
- Display latitude and longitude
- Display location accuracy
- Interactive map using Leaflet
- Display branch locations
- Find the nearest branch
- Show distance from the user to the nearest branch
- Clear current location

## Technologies Used

- Ionic
- Angular
- TypeScript
- Capacitor Geolocation
- Leaflet
- OpenStreetMap
